Exercício 1 - Minha Primeira Página
Objetivo: Criar uma página com título, um parágrafo e um link.
Tarefas:
Crie um arquivo index.html.
Adicione um título (<h1>), um parágrafo (<p>) e um link (<a>) para qualquer site.
Use CSS para mudar a cor do título e centralizar o texto.

Exercício 2 – Caixa Colorida
Objetivo: Criar uma caixa com fundo colorido.
Tarefas:
No HTML, crie uma <div> com o texto "Sou uma caixa!".
No CSS, defina:
Largura: 200px
Altura: 200px
Cor de fundo: azul (ou outra que preferir)
Texto centralizado e na cor branca

Exercício 3 – Lista Estilizada
Objetivo: Criar uma lista de compras estilizada.
Tarefas:
No HTML, crie uma lista não ordenada (<ul>) com 5 itens (ex: pão, leite, café...).
No CSS, altere:
Cor de fundo da lista para cinza claro
Retire os marcadores (list-style: none;)
Altere a cor do texto para verde

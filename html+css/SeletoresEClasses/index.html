Seletores, Classes e ID

Seletores

Seletores em CSS são usados para indicar quais elementos do HTML receberão determinadas regras de estilo. Eles podem ser simples, como o seletor de elemento (p, h1, div), ou mais específicos, como seletores de descendência (div p), de agrupamento (h1, h2, p) ou universais (*). A escolha correta do seletor garante que apenas os elementos desejados sejam estilizados, tornando o código mais limpo e eficiente.

Classes

Classes são definidas no HTML com o atributo class e em CSS são representadas pelo ponto (.). Elas permitem aplicar estilos a vários elementos diferentes ao mesmo tempo, sem depender da hierarquia do documento. Por exemplo, .botao { ... } pode ser aplicada em vários elementos button ou a que precisem ter aparência de botão. As classes são muito úteis para reaproveitar estilos e manter consistência no design.

ID's

IDs são definidos no HTML com o atributo id e em CSS são representados pela cerquilha (#). Diferente das classes, um ID deve ser único em cada página, sendo usado para identificar e estilizar um elemento específico, como #menu-principal { ... }. Além de estilos, IDs também podem ser utilizados em links âncora e em interações com JavaScript. No entanto, recomenda-se usar IDs com cautela no CSS, priorizando classes para maior flexibilidade.

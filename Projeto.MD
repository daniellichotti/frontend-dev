# Integração de Competências Profissionais – React Frontend

Desenvolva um projeto frontend em React no qual você deverá escolher o tema (ex.: catálogo de produtos, filmes, clima, receitas, biblioteca, personagens, jogos, notícias etc.).  
O projeto deve ser totalmente funcional e precisa obrigatoriamente utilizar os seguintes recursos:

### 1. react-router-dom

- Deve haver pelo menos duas rotas principais.
- É necessário usar rota dinâmica (`/item/:id` ou equivalente).
- É necessário tratar erros referentes a rotas não encontradas (404 error) e privar rotas caso haja autenticação.

### 2. Componentização

- O layout deve ser dividido em componentes reutilizáveis, como por exemplo:
- Card
- Header ou Navbar
- Lista
- Página de detalhes
- O aluno deve enviar e receber props entre componentes.

### 3. Consumo de API

- Utilizar [json-server](https://github.com/typicode/json-server) para simular uma API contendo o que você irá precisar para seu frontend.
- O projeto deve ter o CRUD completo.

### 4. useState e useEffect

- useState: controlar estado da aplicação (busca, lista, detalhes, favoritos etc.).
- useEffect: realizar requisições à API, carregamento inicial ou atualização baseada em dependências.

### 5. styled-components

- Todo o estilo deve ser feito com styled-components como ensinado em aula.
- Deve-se criar pelo menos 3 componentes estilizados.
- Deve-se usar uma biblioteca de Ícones estilo phosphor-icons

### Entrega

Antes de iniciar o projeto, o aluno deverá:

1. Escolher o tema do projeto.
2. Enviar uma breve descrição informando:

- Nome da Equipe
- Nome do projeto
- Páginas/rotas planejadas
- Componentes principais
